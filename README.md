# Australian Jiangyin Association website

Static bilingual website for Australian Jiangyin Association Inc.

Before publishing, place the official logo in this folder and name it
`association-logo.jpg`.

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. In **Custom domain**, enter `jiangyin.org.au`.
7. Add the required GitHub Pages DNS records at VentraIP.
8. After the certificate is issued, enable **Enforce HTTPS**.

## Public information only

Do not commit member data, addresses, passwords, certificates, financial records or private meeting documents to this public repository.
